# 부천·인천 분양정보 앱·웹 PRD

> 버전: v0.4 (초안) · 작성일: 2026-10-16 · 최종 수정: 2026-10-18
> 상태: 전체 프로세스 정리 단계. 세부 사항은 항목별로 이어서 확정한다.

## 1. 개요

### 1.1 제품 한 줄 정의
**부천·인천 지역 아파트·오피스텔 분양 정보**를 한곳에 모아 보여주고, 사용자의 청약 조건에 맞는 공고와 일정을 알려주는 모바일 앱과 반응형 웹. (사용자 웹은 푸시 알림을 제외하고 앱과 동일한 기능을 제공한다)

### 1.2 배경
- 분양 정보가 청약홈, LH, 시행사 홈페이지 등에 흩어져 있어 지역 단위로 모아 보기 어렵다.
- 청약 일정(접수일, 당첨자 발표일 등)을 놓치기 쉽다.
- 분양가가 적정한지 판단하려면 주변 시세와 과거 경쟁률을 따로 찾아봐야 한다.

### 1.3 목표
- 부천·인천 지역 분양 정보를 **하루 1회 자동으로 갱신**해서 제공한다.
- 관심 단지와 청약 일정을 **푸시 알림**으로 알려준다.
- 분양가, 주변 시세, 경쟁률, 내 가점을 **한 화면에서 비교·판단**할 수 있게 한다.

### 1.4 타겟 사용자
- 부천·인천 및 인근에서 내 집 마련을 준비하는 무주택자
- 신혼부부, 생애최초 등 특별공급 대상자
- 분양권·입주권 시세에 관심 있는 실수요자

### 1.5 서비스 지역
- 1차: **부천시 전역** (원미구·소사구·오정구, 대장지구 등 신규 택지 포함) + **인천 전역**
- 확장: 경기권은 차후 진행. 전국은 대상으로 하지 않는다.

## 2. 시스템 구성 개요

```
 [공공데이터 API] ──(하루 1회 수집)──▶ [자체 웹서버: APM]
                                          ├─ 데이터 저장 (MariaDB)
                                          ├─ 앱·웹용 API 제공 (PHP)
                                          ├─ 회원 인증 (PHP)
                                          ├─ 관리자 웹페이지 (팝업 관리 포함)
                                          └─ 푸시 발송 요청 ──▶ [Firebase FCM] ──▶ 사용자 기기(앱)
                                                ▲
 [Flutter 앱 (Android / iOS)] ───HTTPS────────┤
 [사용자 웹 (반응형)] ───────────HTTPS────────┘
```

| 구성 요소 | 역할 | 방침 |
|---|---|---|
| **웹서버 (APM)** | 데이터 수집·저장, 앱·웹 API, 회원 인증, 관리자 페이지 | 보유한 리눅스 서버에 Apache + PHP + MariaDB로 구성 |
| **Flutter 앱** | 사용자 화면, 소셜 로그인 SDK 연동, 푸시 수신 | Android / iOS 동시 출시 |
| **사용자 웹** | 사용자 화면 (앱과 동일 기능, 푸시 제외) | 반응형. React를 부분적으로 사용 (Vite 빌드 후 번들 배포) |
| **Firebase** | **FCM(푸시 알림)만 사용** | 인증, DB 등 다른 Firebase 기능은 쓰지 않음 |
| **외부 API** | 공공데이터, 지도, 소셜 로그인 | 서비스키는 서버에만 보관하고 앱에 넣지 않음 |

## 3. 데이터 소스

모두 공공데이터 기반이다. 사용 전에 각 API의 **이용허락범위**(상업적 이용 가능 여부)를 확인하고 기록해 둔다.

| 구분 | 데이터 | 출처 | 용도 |
|---|---|---|---|
| 분양 | 청약홈 분양정보 (APT, 오피스텔·도시형, 무순위·잔여세대, 주택형별 상세) | 한국부동산원 (data.go.kr) | 분양 목록·상세·일정 |
| 분양 | 청약 경쟁률·당첨가점 | 한국부동산원 | 경쟁률, 가점 비교 |
| 분양 | LH 분양·임대 공고 | 한국토지주택공사 | 공공분양 공고 |
| 분양 | GH 공고 | 경기주택도시공사 | 공공분양 공고 (API 제공 여부 확인 필요) |
| 시세 | 아파트 매매·전월세 실거래가 | 국토교통부 | 주변 시세 비교 |
| 시세 | 분양권·입주권 실거래가 | 국토교통부 | 분양권 시세 |
| 시세 | 부동산 통계 (가격지수, 미분양) | 한국부동산원 R-ONE | 지역 동향 |
| 단지 | 공동주택 단지 정보, 건축물대장 | 국토교통부 | 단지 기본정보 |
| 입지 | 학교 정보 | NEIS 교육정보 개방포털 | 주변 학교 |
| 입지 | 대중교통 정보 | TAGO | 주변 교통 |
| 지도 | 지도 표시, 주소→좌표, 주변시설 검색 | **카카오맵 / 카카오 로컬** | 지도·주변시설 |

### 데이터 이용 원칙
- 앱 안에 **출처를 표시**한다. (예: "자료 출처: 한국부동산원 청약홈, 국토교통부")
- 공식 서비스로 오인되지 않게 "청약홈" 등 기관 명칭이나 로고를 앱 브랜딩에 쓰지 않는다.
- 상세 화면에 **면책 문구와 모집공고문 원문 링크**를 둔다. (정확한 일정과 자격은 원문으로 확인하도록 안내)
- 모집공고문 PDF는 재배포하지 않고 원문 링크로 연결한다.

## 5. 회원

### 5.1 가입 방식

| 구분 | 방식 | 처리 방침 |
|---|---|---|
| **일반 회원가입** | 이메일(아이디) + 비밀번호 + **이메일 인증** | PHP 서버에서 가입·로그인 처리. 비밀번호는 안전하게 암호화해서 저장. 휴대폰 본인인증은 하지 않음 |
| **간편가입** | 네이버, 카카오, 구글, **Apple** | 앱에서 각 회사 SDK로 로그인 → 받은 토큰을 서버로 전달 → **서버가 해당 회사에 토큰을 직접 검증** → 회원 조회 또는 신규 가입 |

- Apple 로그인은 iOS App Store 정책 대응을 위해 포함하며, **iOS에서만 노출**한다.
- 인증 메일과 비밀번호 재설정 메일은 **네이버 SMTP**로 발송한다.

**공통 방침**
- 로그인에 성공하면 서버가 **자체 로그인 토큰**을 발급하고, 앱은 이후 요청에 이 토큰을 사용한다.
- 자동 로그인을 지원한다.
- 간편가입 회원은 이메일이 아니라 **"제공자 + 제공자의 고유 ID"** 로 식별한다.
- 이메일이 같다는 이유로 계정을 자동으로 합치지 않는다. 계정 연결은 로그인한 상태에서 사용자가 직접 한다.

### 5.2 가입 절차

```
[가입 방식 선택: 일반 / 네이버 / 카카오 / 구글 / Apple(iOS만)]
        │
        ▼
[1단계: 약관 동의]  ── 필수: 서비스 이용약관, 개인정보 수집·이용, 만 14세 이상 확인
        │             선택: 마케팅 정보 수신, 맞춤 정보(청약 자격) 수집·이용
        ▼
[2단계: 기본 정보]  ── 일반가입: 이메일, 비밀번호, 닉네임
        │             간편가입: 제공자에게서 받은 정보로 자동 입력, 닉네임만 확인
        ▼
[2-1단계: 이메일 인증 (일반가입만)]
        │             입력한 이메일로 6자리 인증 코드 발송 → 앱에서 코드 입력 → 일치하면 가입 확정
        │             (코드 재발송 가능, 유효 시간과 재시도 횟수는 제한)
        ▼
[3단계: 맞춤 정보 (선택, 건너뛰기 가능)]
        │             관심 조건 / 청약 자격 / 특별공급 해당 여부
        ▼
[4단계: 알림 설정]  ── 푸시 알림 허용, 알림 종류 선택
        │
        ▼
     가입 완료 → 홈
```

- 3단계 맞춤 정보는 **가입할 때 건너뛸 수 있고**, 나중에 "내 정보"에서 입력·수정할 수 있다. 가입 이탈을 줄이기 위해서다.

### 5.3 가입 항목

#### (1) 기본 정보
| 항목 | 일반가입 | 간편가입 | 비고 |
|---|---|---|---|
| 이메일 | 필수 (인증 필요) | 제공자가 주면 자동 입력 | 카카오는 선택 동의, 애플은 숨김 이메일일 수 있음 |
| 비밀번호 | 필수 | 없음 | |
| 닉네임 | 필수 | 자동 입력 후 수정 가능 | |
| 휴대폰 번호 | 수집 안 함 | 수집 안 함 | 휴대폰 본인인증을 하지 않으므로 받지 않음 |

#### (2) 관심 조건 (선택) – 맞춤 추천·알림에 사용
| 항목 | 예시 |
|---|---|
| 관심 지역 | 부천(원미구 / 소사구 / 오정구), 인천(구·군 단위), 부천·인천 전체 |
| 관심 주택 유형 | 아파트, 오피스텔, 도시형생활주택, 공공분양 |
| 희망 평형(전용면적) | 59㎡ 이하, 60~84㎡, 85㎡ 초과 |
| 예산(가격대) | 구간 선택 |

#### (3) 청약 자격 정보 (선택) – 가점 계산·자격 안내에 사용
| 항목 | 용도 |
|---|---|
| 무주택 여부 / 무주택 기간 | 가점 계산, 자격 판단 |
| 세대주 여부 | 1순위 자격 판단 |
| 청약통장 종류 / 가입 기간 / 납입 횟수 | 가점 계산, 순위 판단 |
| 부양가족 수 | 가점 계산 |
| 거주지 (시·도, 해당 지역 거주 기간) | 해당지역·기타지역 우선공급 판단 |
| 과거 당첨 이력 (재당첨 제한 여부) | 자격 판단 |

#### (4) 특별공급 해당 여부 (선택)
| 항목 |
|---|
| 신혼부부 (혼인 기간) |
| 생애최초 |
| 다자녀 (자녀 수) |
| 노부모 부양 |
| 기관추천 등 기타 |

> 청약 자격 정보는 민감도가 높으므로 **선택 수집**으로 하고, 별도 동의를 받으며, 언제든 삭제할 수 있게 한다.
> 이 정보로 계산한 결과는 **참고용**이며 실제 자격은 모집공고문과 청약홈에서 확인하도록 안내한다.

#### (5) 수신 동의
| 항목 | 비고 |
|---|---|
| 푸시 알림 수신 (서비스 알림) | 관심단지 일정, 신규 공고 |
| 마케팅 정보 수신 (광고성 알림) | **별도 동의 필요.** 야간(21시~08시) 광고성 알림은 추가 동의 필요 |

### 5.4 로그인 이후 계정 관리
- 비밀번호 찾기·재설정 (일반회원, 가입한 이메일로 재설정 메일 발송)
- 내 정보 수정 (맞춤 정보, 알림 설정)
- 간편로그인 계정 연결·해제
- 로그아웃
- **회원 탈퇴**: 앱 안에서 바로 할 수 있어야 한다 (iOS 필수 요건). 탈퇴하면 소셜 계정 연결도 해제하고 개인정보를 정책에 따라 파기한다.

## 6. 기능 요구사항 (MVP)

### 6.1 분양 목록
- 부천·인천 지역 분양 공고를 목록으로 보여준다.
- 상태 구분: 분양 예정 / 접수 중 / 접수 마감 / 당첨자 발표 완료
- 필터: 지역(시·구·군), 주택 유형, 평형, 분양가, 상태
- 정렬: 접수일 순, 최신 등록 순, 분양가 순
- 회원이면 관심 조건에 맞는 공고를 상단에 추천한다.

### 6.2 분양 상세
- 기본 정보 (비회원 포함): 단지명, 위치, 주택 유형, 공급 규모, 주요 일정, 모집공고문 원문 링크
- 중요 정보 (회원 전용): 주택형별 분양가, 경쟁률·당첨가점, 주변 시세 비교, 내 가점 비교
- 비회원이 중요 정보 영역을 보면 내용을 가리고 "로그인하면 볼 수 있어요" 안내와 로그인 버튼을 보여준다.
- 면책 문구와 출처 표시

### 6.3 청약 캘린더
- 공고일, 특별공급 접수일, 1·2순위 접수일, 당첨자 발표일, 계약일을 캘린더로 보여준다.
- 회원은 관심 단지 일정만 따로 볼 수 있다.

### 6.4 지도·주변시설
- **카카오맵**으로 분양 단지 위치를 지도에 표시한다.
- **카카오 로컬**로 주변 지하철역, 버스정류장, 학교, 마트, 병원 등을 보여준다.
- 주소→좌표 변환은 데이터 수집 때 서버에서 한 번만 처리하고 저장한다.

### 6.5 관심 단지·푸시 알림
- 관심 단지 등록·해제
- 알림 종류:
  - 관심 단지의 접수 시작 전날 / 당일, 당첨자 발표일
  - 내 관심 조건에 맞는 신규 공고 등록
  - 공지사항, 마케팅 알림 (동의한 사람만)
- 알림 종류별로 켜고 끌 수 있다.

### 6.6 시세·경쟁률·가점 계산기
- **주변 시세**: 분양 단지 주변 아파트의 최근 실거래가와 분양가 비교
- **분양권 시세**: 분양권·입주권 실거래가
- **경쟁률·당첨가점**: 해당 단지(마감 후) 및 같은 지역(부천·인천) 내 과거 유사 단지 결과
- **가점 계산기**: 무주택 기간, 부양가족 수, 청약통장 가입 기간으로 가점 계산 (84점 만점). 회원은 결과를 저장하고 단지별 당첨가점과 비교할 수 있다.

### 6.7 공지·고객센터
- 공지사항 목록·상세
- 1:1 문의 작성 및 답변 확인 (회원)
- FAQ (선택)

### 6.8 광고·제휴
- 앱 안의 지정된 영역에 광고 배너를 노출한다. (위치, 형태 추후 결정)
- 광고에는 **"광고" 표시**를 하고, 과장 광고가 되지 않도록 검수한다.

### 6.9 팝업
- 관리자가 지정한 분양정보를 **메인 진입 시 팝업 레이어**로 노출한다. (웹은 홈 접속 시, 앱은 실행 후 홈 진입 시)
- 비회원·회원 모두에게 노출한다.
- 팝업을 누르면 해당 분양 상세 화면으로 이동한다.
- 사용자는 팝업을 **닫거나 "오늘 하루 안 보기"** 를 선택할 수 있다.
- 관리자 설정 항목:
  - **노출 대상**: 웹만 / 앱만 / 웹+앱 (팝업마다 선택)
  - **노출 기간**: 시작일 ~ 종료일
  - **노출 순서와 동시 노출 수**: 여러 개일 때 순서, 한 번에 보여줄 최대 개수

## 7. 처리 프로세스

### 7.1 데이터 수집 (웹서버, 하루 1회)
```
[매일 새벽 정해진 시각에 자동 실행]
  1. 공공데이터 API 호출 (분양정보 → 경쟁률 → 실거래가 순)
  2. 부천·인천 지역 데이터만 골라냄
  3. 기존 데이터와 비교해서 신규·변경 사항을 반영
  4. 신규 단지는 주소를 좌표로 변환해서 저장
  5. 수집 결과(성공/실패, 건수)를 로그로 남김
  6. 신규 공고나 일정 변경이 있으면 → 알림 대상자를 골라 푸시 발송
```
- API 장애로 실패하면 **기존 데이터를 유지**하고 재시도한다. 계속 실패하면 관리자에게 알린다.
- 관리자가 수동으로 다시 수집할 수 있다.

### 7.2 푸시 알림
```
[알림 사건 발생: 신규 공고 / 접수일 임박 / 발표일 / 공지]
  → 서버가 알림 대상 회원과 기기 추림 (알림 설정, 수신 동의 확인)
  → FCM으로 발송 요청
  → 사용자 기기에 알림 표시 → 누르면 해당 화면으로 이동
```
- 앱을 설치하거나 로그인할 때 기기의 푸시 토큰을 서버에 등록하고, 바뀌면 갱신한다.

### 7.3 인증
```
[일반 가입] 앱: 정보 입력 → 서버: 6자리 코드 메일 발송 (네이버 SMTP) → 앱: 코드 입력 → 서버: 확인 후 가입 확정
[일반 로그인] 앱: 이메일·비밀번호 입력 → 서버: 확인 (이메일 인증 완료 회원만) → 로그인 토큰 발급
[간편] 앱: SDK 로그인 → 토큰 전달 → 서버: 제공자에게 검증 → 회원 조회/가입 → 로그인 토큰 발급
[공통] 앱: 토큰 안전하게 저장 → 이후 요청에 사용 → 만료되면 자동 갱신
```

## 10. 정책·법적 고려사항

- **공공데이터 이용허락범위**: API마다 확인하고 기록한다.
- **개인정보 처리방침**: 수집 항목, 목적, 보관 기간, 파기 절차를 명시한다. 특히 청약 자격 정보는 선택 동의를 따로 받는다.
- **정보통신망법**: 광고성 푸시는 별도 수신 동의가 필요하고, 야간 발송은 추가 동의가 필요하다. 수신 동의 사실은 정기적으로 다시 안내한다.
- **표시광고법**: 분양 광고는 "광고"로 표시하고 과장 광고를 하지 않는다.
- **공인중개사법**: 매물 중개나 수수료 모델은 넣지 않는다. 정보 제공 서비스로 한정한다.
- **앱스토어 정책**: 앱 안에서 회원 탈퇴 제공 (iOS 필수), 소셜 로그인 관련 요건 확인.
- **면책**: 데이터는 참고용이며 실제 청약은 모집공고문과 청약홈 기준이라고 안내한다.

> 출시 전에 약관과 개인정보 처리방침은 전문가 검토를 받는 것을 권장한다.
