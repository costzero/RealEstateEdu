## 1\. 개요

### 1.1 목적

신축 아파트·오피스텔 등의 분양정보를 공공 API로 모아, 반응형 웹과 모바일 앱(Android/iOS)으로 제공합니다. 회원은 관심 단지와 관심 조건을 저장하고 청약 일정 알림을 받을 수 있습니다.

### 1.2 범위

| 구분 | 1차 범위 | 1차 제외 |
| --- | --- | --- |
| 분양 유형 | 아파트, 오피스텔(도시형생활주택·민간임대 등 청약홈 제공 유형 포함) | 상가 |
| 플랫폼 | 반응형 웹, Android 앱, iOS 앱 | \- |
| 회원 | 자체 회원가입(이메일/비밀번호), 네이버·카카오 로그인 | \- |

## 3\. 시스템 구성

| 구성 요소 | 기술 | 비고 |
| --- | --- | --- |
| 웹 서버 | Linux + APM (Apache, PHP, MariaDB) | 이미 보유 중인 서버 사용 |
| 백엔드 | 순수 PHP (프레임워크 미사용) | 반응형 웹 화면과 앱용 REST API를 함께 제공 |

| 반응형 웹 | PHP 서버 렌더링 + HTML/CSS/JS | PC·태블릿·모바일 브라우저 대응 |

| 푸시 알림 | FCM (Firebase Cloud Messaging) | Android/iOS 공통 |
| 이메일 발송 | 미정 | [9\. 미정 사항](#9-%EB%AF%B8%EC%A0%95-%EC%82%AC%ED%95%AD) |

| 분양 데이터 | 공공데이터포털 “한국부동산원 청약홈 분양정보 조회 서비스” | 4장 참고 |

```
[공공 API] --(정기 수집 배치)--> [PHP 백엔드 + MySQL] --(HTML)--> [반응형 웹]

                                         |
                                         +--(FCM / 이메일)--> [회원 알림]
```

## 4\. 분양 데이터

### 4.1 데이터 출처

-   공공데이터포털의 "한국부동산원 청약홈 분양정보 조회 서비스"를 사용합니다.
-   이 서비스는 APT 분양정보와 오피스텔/도시형생활주택/민간임대 분양정보 등을 따로 제공합니다. 실제 사용할 오퍼레이션, 응답 항목, 호출 한도는 API 키를 발급받은 뒤 확인해서 이 문서에 반영합니다.

### 4.2 수집 방식 (제안)

-   사용자 요청마다 공공 API를 직접 부르지 않습니다. 서버 배치(cron)가 정기적으로 데이터를 받아 MySQL에 저장하고, 웹과 앱은 자체 DB를 조회합니다.
-   이렇게 하면 API 호출 한도와 응답 지연의 영향을 줄이고, 관심 조건 매칭과 알림 발송에 같은 데이터를 쓸 수 있습니다.
-   수집 주기와 중복·변경 처리 기준은 미정입니다.

### 4.3 주요 항목 (예상)

API 응답을 확인한 뒤 확정합니다.

-   단지명, 분양 유형(아파트/오피스텔 등), 공급 위치(시도·시군구·주소)
-   공급 규모(세대수), 주택형·전용면적, 분양가
-   모집공고일, 청약 접수 일정(특별공급·1순위·2순위 등), 당첨자 발표일, 계약 일정
-   시행사·시공사, 문의처, 청약홈 공고 링크
