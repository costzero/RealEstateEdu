# 보안 및 개인정보 규칙

- 비밀번호는 평문 저장 금지, 검증된 단방향 해시(bcrypt/argon2 등)만 사용한다
- API 키, DB 접속정보 등 비밀값은 환경변수로 관리하고 저장소에 커밋하지 않는다 (.env는 .gitignore)
- 모바일 앱과 웹 프론트 번들에는 비밀 키를 넣지 않는다. 외부 API 호출은 서버를 경유한다
- 모든 사용자 입력은 서버에서 검증하고, SQL은 파라미터 바인딩을 사용한다
- 외부 API 데이터와 팝업 내용 등 화면에 출력하는 값은 XSS 방지를 위해 이스케이프한다
- 로그인 시도 횟수를 제한하여 무차별 대입 공격을 막는다
- 개인정보는 필요한 항목만 수집하고, 로그에 개인정보와 토큰을 남기지 않는다
