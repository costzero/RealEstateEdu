# 공공API 연동 규칙

- 공공API는 클라이언트(웹/앱)가 직접 호출하지 않고 서버가 호출한다
- 호출 한도와 응답 지연에 대비해 서버에서 주기적으로 수집/캐싱하고 자체 DB를 조회한다
- 외부 응답 형식을 그대로 앱에 노출하지 않고, 내부 표준 모델로 변환하는 계층을 둔다
- 유형(아파트, 오피스텔, 상가)별로 필드가 다르므로 공통 필드와 유형별 필드를 구분한다
- API 장애, 한도 초과, 빈 응답 시에는 재시도 후 이전 캐시를 사용하고, 빈 응답으로 기존 데이터를 덮어쓰지 않는다
- 데이터 출처를 화면에 표기한다. 각 API의 이용약관/라이선스 확인 결과는 PRD에 기록한다
- 재시도 횟수, 수집 주기, 캐시 유효 기간 등 구체 수치는 PRD에서 확정하고, 확정 전에는 임의로 정하지 않는다
